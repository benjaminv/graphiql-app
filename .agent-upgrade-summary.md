## Upgrade Summary: GraphiQL Desktop v3 → v5

### 1. GraphiQL Core: v3 → v5 (Breaking Change)

| | Before | After |
|---|---|---|
| `graphiql` | `^3.0.10` | `^5.2.2` |
| `@graphiql/plugin-explorer` | `^3.0.1` | `^5.1.1` |
| `@graphiql/toolkit` | `^0.9.1` | `^0.11.3` |
| Editor engine | CodeMirror | **Monaco Editor** |
| `vite` | `^5.0.10` | `^6.3.4` |
| `electron-builder` | `^24.9.1` | `^26.8.1` |
| New: `vite-plugin-monaco-editor` | — | `^1.1.0` |

Key API migration in GraphiQLWrapper.tsx: controlled props (`query=`, `variables=`, `headers=`) → uncontrolled (`initialQuery=`, `initialVariables=`, `initialHeaders=`). History plugin added. Style imports updated.

### 2. Global Settings System (New)

- **settingsStore.ts** — Zustand store for global theme (`system`/`light`/`dark`) and `showInnerSettings` toggle
- **SettingsPanel.tsx** — Settings overlay accessible from the tab bar
- Theme is now **global** (applied via `forcedTheme` to GraphiQL + wrapper UI), no longer per-tab
- Inner GraphiQL settings (persist headers toggle, clear data) can be shown/hidden globally

### 3. Tab Bar UX Improvements

In TabBar.tsx:
- **Drag-and-drop** reordering (with visual feedback)
- **Double-click** to rename
- **Close confirmation** dialog for non-empty tabs (via new ConfirmDialog.tsx)
- Settings gear button in the tab bar

### 4. Header Persistence

In GraphiQLWrapper.tsx:
- `shouldPersistHeaders` is **locked to `true`** via `LOCKED_STORAGE_KEYS` — desktop app always persists headers
- **`HeaderSync`** component — when a new inner query tab is added, it inherits the previous tab's headers automatically

### 5. Data Persistence Fix (Critical)

**Problem**: Chromium's `localStorage` in Electron never reliably flushes to disk. All user data (tabs, queries, headers) was lost on every app quit.

**Solution**: File-backed persistence that bypasses `localStorage` entirely:
- **electron/main.ts** — IPC handlers write `tabs-data.json` to `~/Library/Application Support/graphiql-desktop/`. Debounced (1s) with forced flush on quit.
- **electron/preload.ts** — Exposes `saveTabs()` / `loadTabs()` to renderer via `contextBridge`
- **src/store/tabStore.ts** — Custom `fileBackedStorage` adapter for Zustand persist: reads from file on startup, writes to both localStorage (fast cache) and file (durable) on every change
